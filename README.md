## FAQ

### What is XCutors?

XCutors is a collection package for Windows that bundles several popular Roblox script executors and a universal loader. It allows users to easily switch between different executors and manage Lua scripts for running in Roblox games.

### Is this tool safe to use?

XCutors is designed as a development and testing tool for Lua scripting. It does not contain malicious software, but you should always scan downloaded files with your anticomponent. Usage of script executors may violate Roblox's Terms of Service, so use them at your own risk and responsibly.

### Which Windows versions are supported?

XCutors is compatible with Windows 10 and Windows 11. It is optimized for 64-bit systems and requires administrator privileges for injection operations.

### Why do I need a password to extract the files?

The password protection is used to prevent automated scanning and distribution of the tools to unintended audiences. It helps maintain the project's distribution control and community focus.

### Can I add my own executors to the collection?

The universal loader (xcutorsLoader) is designed to be configurable. While it comes with preset options, advanced users can modify its configuration files to potentially add support for other compatible executors.

### Do these executors work on all Roblox games?

No, some games employ robust anti-enhance systems that may detect or block script execution. The effectiveness can vary between games and over time as game security updates. Always check the latest compatibility information.

### How often are the executors updated?

The updates are provided on a best-effort basis. The XCutors team monitors compatibility and pushes updates to the collection as the bundled executors receive patches or when compatibility issues arise.

### What kind of scripts can I run?

You can run most standard Lua scripts written for the Roblox environment. This includes UI creation, automation, and gameplay modifications. The scripts must be compatible with the specific executor's API and capabilities.
